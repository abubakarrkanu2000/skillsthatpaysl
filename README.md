# Skills That Pay website

Open `index.html` in your browser, or use the VS Code Live Server extension.

## Project structure

- `index.html`: page content and clearly labeled sections.
- `css/style.css`: site styles and responsive layouts. Rule order is intentional; later rules preserve the existing overrides.
- `assets/images/`: original website images, unchanged.

Edit text in `index.html` and styles in `css/style.css`. Keep relative file paths intact when moving the project. Montserrat loads from Google Fonts and requires an internet connection. This site uses native anchor navigation and CSS interactions, so no JavaScript file is needed.

The code was reorganized without changing the website content, style rules, image files, or link destinations.
